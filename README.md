\# 🛒 E-Commerce Website



A full-stack E-Commerce web application developed using React.js and Node.js.



\## 📌 Project Overview



This project is an online shopping application that allows users to browse products and manage their shopping experience through a simple web interface.



The project contains both frontend and backend components.



\## ✨ Features



\- 🛍️ Product listing

\- 🔍 Product browsing

\- 🛒 Shopping cart functionality

\- 📦 Order management

\- 👨‍💼 Admin product management

\- 👨‍💼 Admin order management

\- 🔗 Backend API integration

\- 📱 Responsive user interface



\## 🛠️ Technologies Used



\### Frontend

\- React.js

\- JavaScript

\- HTML

\- CSS

\- Vite



\### Backend

\- Node.js

\- Express.js

\- MongoDB

\- REST API
